SynthController 🎹🔊
Advanced MIDI Synthesizer with GUI

Um sintetizador de áudio de qualidade profissional com suporte polifônico, múltiplos tipos de forma de onda e processamento em tempo real. Apresenta uma interface gráfica intuitiva para controle de parâmetros e entrada MIDI.

Features ✨
12+ Tipos de Forma de Onda (Seno, Quadrada, Dente de Serra, FM, Ruído, etc.)
Suporte Polifônico (Até 64 vozes)
Controle de Envelope ADSR (Curvas Lineares/Exponenciais)
Visualização de Forma de Onda em Tempo Real
Teclado MIDI Virtual (Teclado do computador como controlador)
Carregamento de Wavetable (Importação de forma de onda personalizada)
Motor de Áudio de Baixa Latência
Technologies 🛠️
Python
NumPy (Processamento de áudio)
Tkinter (Interface Gráfica)
SoundDevice (Entrada/Saída de áudio)
Mido (Suporte MIDI)
Matplotlib (Visualização)
