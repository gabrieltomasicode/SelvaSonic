# SynthController 🎹🔊  

**Advanced MIDI Synthesizer with GUI**  

A professional-grade audio synthesizer with polyphonic support, multiple waveform types, and real-time processing. Features an intuitive GUI for parameter control and MIDI input.  

## Features ✨  
- **12+ Waveform Types** (Sine, Square, Sawtooth, FM, Noise, etc.)  
- **Polyphonic Support** (Up to 64 voices)  
- **ADSR Envelope Control** (Linear/Exponential curves)  
- **Real-Time Waveform Visualization**  
- **Virtual MIDI Keyboard** (Computer keyboard as controller)  
- **Wavetable Loading** (Custom waveform import)  
- **Low-Latency Audio Engine**  

## Technologies 🛠️  
- Python  
- NumPy (Audio processing)  
- Tkinter (GUI)  
- SoundDevice (Audio I/O)  
- Mido (MIDI support)  
- Matplotlib (Visualization)
